# Blueprint Architecture

## Principle

Questions are reusable.
Blueprints define the exam.

## Hierarchy

Board
    ↓
Blueprint
    ↓
Assessment
    ↓
Attempt
    ↓
Results

## Board

Defines the exam identity.

Examples:
- LET
- Civil Service

## Blueprint

Defines:
- Question count
- Topic distribution
- Difficulty distribution
- Cognitive level
- Time limit

## Assessment

Generated from:
- Blueprint
- Question Repository
- User settings
