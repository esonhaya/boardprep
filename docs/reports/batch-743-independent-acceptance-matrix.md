## Browser harness contract

- The runner exports the exact committed tree with `git archive HEAD`; the application, reviewer and account servers use separate synthetic storage/session directories and loopback-only listeners. Test evidence does not include `account-fixture-private.json`.
- Browser projects are serialized with one worker and zero retries; Playwright tests are bounded, navigation uses explicit state assertions, and failures retain screenshot/trace evidence. Server lifecycle contracts cover readiness, child shutdown and fixture cleanup.
- The account journey now deliberately removes the synthetic auth cookie and its matching `sess_<id>` file in the private temporary session directory, then reauthenticates, resumes one saved answer, checks the original server deadline did not increase, submits once and checks one history result.
- The account journey does not record usernames, passwords, recovery codes, cookies, session IDs, answers or learner records. Review screenshots mask question/result content. Evidence files are private and artifact hashes cover retained regular files while excluding the private fixture handoff and manifest self-reference.
- The final suite certification rejects absent mandatory scenario IDs, stale/mismatched build SHA, dirty checkout, incomplete viewport evidence, failing/flaky tests, missing preflight, or absent result artifacts. Extra viewport checks may remain, but all five required widths must be present.
- Any skipped required test makes the run incomplete. The JSON result summary may not describe a run with skipped or unrun tests as completed.
